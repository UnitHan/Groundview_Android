2. 시스템 요구사항
   - Windows 10/11 (64비트)
   - Python 3.10 이상 (자동 설치됨)
   - 최소 4GB RAM
   - 500MB 이상의 디스크 공간

3. 데이터 수집 및 개인정보
   GroundView는 다음 데이터를 로컬에 저장합니다:
   - Gemini API Key (암호화되어 저장됨)
   - 애플리케이션 설정
   - 캡처한 스크린샷 및 UI 계층 구조
   - 사용 로그

   수집된 데이터는 귀하의 컴퓨터에만 저장되며 외부로 전송되지 않습니다.
   단, Gemini OCR 기능 사용 시 스크린샷이 Google Gemini API로 전송됩니다.

4. 제3자 서비스
   이 소프트웨어는 다음 제3자 서비스를 사용할 수 있습니다:
   - Google Gemini API (사용자가 API Key 제공 시)
   - ADB (Android Debug Bridge)
   - PaddleOCR

   제3자 서비스 사용 시 해당 서비스의 약관이 적용됩니다.

5. 보증 제한
   이 소프트웨어는 "있는 그대로" 제공되며, 명시적이거나 묵시적인 어떠한 보증도
   하지 않습니다. 상품성, 특정 목적에의 적합성 및 비침해에 대한 보증을 포함하되
   이에 국한되지 않습니다.

6. 책임의 제한
   저자 또는 저작권 소유자는 계약, 불법 행위 또는 기타의 경우를 막론하고
   소프트웨어로부터 발생하거나 소프트웨어와 관련하여 발생하는 청구, 손해 또는
   기타 책임에 대해 어떠한 책임도 지지 않습니다.

7. 설치 경로 및 파일
   이 소프트웨어는 다음 위치에 파일을 생성합니다:
   - 프로그램 파일: 선택한 설치 경로
   - 사용자 데이터: %APPDATA%\GroundView
   - 캐시: %LOCALAPPDATA%\GroundView
   - OCR 모델: %USERPROFILE%\.paddleocr

8. 자동 업데이트
   현재 버전은 자동 업데이트를 지원하지 않습니다. 새 버전은 수동으로
   다운로드하여 설치해야 합니다.

9. 제거
   제어판 > 프로그램 추가/제거를 통해 언제든지 소프트웨어를 제거할 수 있습니다.
   제거 시 사용자 데이터 삭제 여부를 선택할 수 있습니다.

10. 약관 동의
