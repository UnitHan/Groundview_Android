# GroundView 인스톤러 개선 사항

## ✨ 새로운 설치 경험

### 🎯 추가된 기능

1. **📜 라이선스 동의 화면**
   - EULA (최종 사용자 라이선스 계약) 표시
   - 한글/영문 약관 포함
   - 개인정보 처리 방침 명시
   - 제3자 서비스 사용 고지

2. **📁 설치 경로 선택**
   - 기본 경로: `C:\Program Files\GroundView`
   - 사용자 정의 경로 선택 가능
   - 필요한 디스크 공간 표시 (~500MB)

3. **🎨 향상된 UI**
   - Welcome 페이지 (프로그램 소개)
   - License 페이지 (약관 동의)
   - Directory 페이지 (설치 경로)
   - Components 페이지 (옵션 선택)
   - Installation 페이지 (진행률)
   - Finish 페이지 (완료 후 실행)

4. **⚙️ 설치 옵션**
   - 바탕화면 바로가기 생성
   - 시작 메뉴 바로가기 생성
   - 빠른 실행 바로가기
   - 설치 후 자동 실행

5. **🗑️ 제거 옵션**
   - 사용자 데이터 보존/삭제 선택
   - 설정 파일 경로 안내
   - 완전 제거 확인 메시지

## 🛠️ 빌드 방법

```bash
# 1. 빌드 (라이선스 포함)
npm run build

# 2. 인스톨러 생성
npm run dist

# 생성 파일: dist/electron/GroundView-Setup-0.0.5.exe
```

## ⚠️ 주의사항

### 그래픽 파일 (선택사항)
인스톨러 커스터마이징을 위한 그래픽 파일은 선택사항입니다:
- `build/installerHeader.bmp` (150x57)
- `build/installerSidebar.bmp` (164x314)

없으면 기본 NSIS 그래픽 사용. 자세한 내용은 `build/GRAPHICS.md` 참조.

### 아이콘 파일
루트 디렉토리에 `icon.ico` 필요 (없으면 기본 아이콘 사용)

## 🎁 추가 기능

### 설치 전 체크
- 이미 설치된 경우 자동 감지
- 기존 버전 제거 옵션 제공
- Python 설치 확인 (선택적 경고)

### 설치 후
- 레지스트리 등록 (제어판 표시)
- 바로가기 생성
- 첫 실행 시 Python 패키지 자동 설치

### 제거 시
- 사용자 데이터 삭제 여부 선택
- 설정 파일 경로 안내
- 완전 제거 확인

## 🚀 테스트

```bash
# 1. 개발 빌드

# 2. 설치 테스트

제어판 > 프로그램 제거
```

## 📞 문제 해결

### 빌드 오류
```bash
# NSIS 설정 오류 시
npm run dist:verbose

# 그래픽 파일 없음 오류
# → build/GRAPHICS.md 참조하여 생성
# 또는 package.json에서 해당 옵션 제거
```

### 설치 오류
- 관리자 권한으로 실행
- 기존 버전 완전 제거 후 재설치
- 로그 확인: `%TEMP%\GroundView-Setup.log`
