Product Brief

GroundView — TestGPT를 더 빠르고 똑똑하게 만드는 모바일 UI 인스펙터

GroundView는 TestGPT(Ankylo)에서 앱 테스트케이스를 작성할 때, 화면 텍스트와 버튼 정보를 빠르게 수집하고 Appium 스크립트까지 바로 연결해주는 AI 기반 테스트 작성 보조 도구입니다.

TestGPT 케이스 작성 최적화
Gemini Vision OCR
Appium 스크립트 지원
ListView 카드 UI
배경 목표 핵심 기능 초보자 워크플로우 화면 예시 비교 스펙 정보

배경: 왜 GroundView가 필요했는가

TestGPT 테스트케이스 작성의 현실

  • 앱 화면의 텍스트 요소를 일일이 복사해서 케이스로 옮겨 적는 시간이 큼
  • WebView 등 DOM 분석이 어려운 화면은 텍스트 인식이 거의 불가능
  • 버튼/로케이터 정보를 빠르게 정리할 도구가 부족

기존 인스펙터의 한계

  • Tree View 중심이라 버튼 정보가 한눈에 들어오지 않음
  • 스크립트 작성 환경과 분리되어 테스트 작성 흐름이 끊김
  • ADB 환경에서 Appium Inspector 세팅이 번거로움

목표: 초보자도 빠르게 쓰는 테스트 작성 도구

GroundView는 “복사 → 붙여넣기 → 스크립트화”의 흐름을 끊지 않는 것을 목표로 합니다.

TestGPT/Ankylo 사용자에게는 “텍스트 수집 + 로케이터 정리 + Appium 스크립트”가 하나의 흐름이어야 합니다. GroundView는 이 과정을 한 화면에서 끝내는 것을 핵심 가치로 두었습니다.

핵심 기능

Gemini Vision OCR (텍스트/표 인식)

WebView 등 DOM 분석이 어려운 화면에서도 화면 캡처만으로 텍스트와 표 데이터를 추출합니다.

로케이터 추천 & 자동 생성

팝업에서 LLM 명령을 사용해 실시간 로케이터 추천을 보여줍니다.

Appium 스크립트 즉시 제공

버튼 요소를 더블클릭하면 Python/Java용 Appium 스크립트를 바로 확인할 수 있습니다.

카드형 ListView UI

버튼 요소 정보를 카드로 보여줘 초보자도 빠르게 필요한 값을 찾을 수 있습니다.

ADB 환경에서도 바로 사용

Appium Inspector 없이도 스크립트 작성을 이어갈 수 있게 ADB 기반 흐름을 지원합니다.

큰 화면, 쉬운 확인

Appium Inspector보다 큰 화면으로 앱 UI를 선명하게 확인할 수 있도록 설계했습니다.

초보자 워크플로우 (TestGPT 기준)

1

ADB 연결

기기를 연결하고 GroundView에서 ADB를 선택합니다.

2

화면 캡처 & 요소 확인

앱 화면을 캡처하고 ListView 카드에서 버튼/텍스트 정보를 확인합니다.

3

텍스트/표 OCR

DOM 인식이 불가능한 화면은 Gemini Vision OCR로 텍스트와 표를 수집합니다.

4

로케이터 선택

팝업의 LLM 추천 로케이터를 확인하고 최적 값을 결정합니다.

5

Appium 스크립트 복사

Python/Java 스니펫을 복사해 테스트 코드에 바로 붙여넣습니다.

6

TestGPT 케이스 완성

수집된 텍스트와 로케이터를 바탕으로 TestGPT 테스트케이스를 빠르게 완성합니다.

스펙 정보 (요약)

필수 구성

  • ADB 연결 (Android 디바이스/에뮬레이터)
  • GroundView 실행 환경

선택/확장

  • Gemini Vision 연동 시 OCR/LLM 로케이터 추천 사용
  • Appium 스크립트 작성 시 Python/Java 프로젝트에 적용
초보자를 위한 팁

처음에는 “텍스트 수집 → TestGPT 케이스 작성” 흐름만 익힌 뒤, 로케이터 추천과 Appium 스크립트 기능을 단계적으로 확장하면 가장 빠르게 익힐 수 있습니다.

의도된 가치

테스트케이스 품질 향상

텍스트/표 정보를 빠르게 확보해 테스트케이스 정확도와 재현성을 높입니다.

학습 비용 절감

ListView 카드 UI와 스크립트 팝업으로 초보자도 쉽게 접근할 수 있습니다.
